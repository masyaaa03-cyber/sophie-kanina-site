# Сайт Софьи Каниной — тестовая версия

Одностраничный сайт психолога-психоаналитика. Источник текстов и фото — текущий сайт sophiekanin.aqulas.me (с согласия Софьи). План и решения — в документе «План сайта Софьи Каниной».

## Что где лежит

- `index.html` — вся страница: тексты, стили, разметка.
- `fonts/` — шрифты Unbounded (заголовки) и Golos Text (текст), лицензия SIL OFL 1.1, лежат на самом сайте, без серверов Google.
- Фото пока подгружаются с текущего сайта на Aqulas. Перед переездом скачать их в `images/` и заменить адреса.

## Пометки тестовой версии (убрать перед запуском)

- Жёлтые плашки «уточнить» — вопросы к Софье.
- Полосатые блоки «Место для фото» — 5 фото, которые генерируются по промптам из плана.
- Строка `<meta name="robots" content="noindex, nofollow">` закрывает тест от поисковиков.

## Как поправить текст

Найти фразу в `index.html` (Ctrl+F) и заменить. Цвета — в начале файла, блок `:root`.
